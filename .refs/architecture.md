# Architecture

Next.js 16 App Router app written in TypeScript and styled with Tailwind CSS
v4. Scaffolded with `create-next-app@16.4.2` using the recommended defaults
(App Router, Turbopack, Cache Components, no `src/` dir), with Biome in place
of ESLint and the `@/*` import alias removed.

Code is the truth. This file explains the *why* behind the shape it takes.

## Stack

- **Framework:** Next.js 16 (`next`, `react`, `react-dom` 19). Turbopack is
  the default bundler for `next dev` and `next build`.
- **Language:** TypeScript, `strict: true`. Route-aware helper types
  (`LayoutProps<"/">`, `PageProps<...>`) are generated by `next typegen`
  into `.next/types`; `npm run typecheck` runs typegen before `tsc` so a
  fresh clone typechecks without a prior `next dev`/`next build`.
- **Styling:** Tailwind CSS v4, CSS-first config. `app/globals.css` does
  `@import "tailwindcss"` and holds `@theme` tokens. There is no
  `tailwind.config.*` and no PostCSS config: Tailwind runs through the
  `@tailwindcss/turbopack` loader registered under `turbopack.rules` in
  `next.config.ts`.
- **Lint/format:** Biome (`biome.json`), see
  [conventions.md](./conventions.md#imports).
- **Git hooks:** lefthook (`lefthook.yml`), see [ci-cd.md](./ci-cd.md).
- **Toolchain:** Node 24 LTS, pinned in `.tool-versions` (asdf) and
  `engines.node` in `package.json`. npm is the package manager
  (`package-lock.json`).

## Layout

- `app/` — App Router root. `layout.tsx` is the root layout (Geist and Geist
  Mono via `next/font/google`, `metadata`), `page.tsx` renders the archive
  index at `/`, `globals.css` holds the design tokens. Icons use the
  metadata file conventions: `icon.svg` is the source (ink tile, paper 2×2
  grid echoing the "All" domain glyph, coin in the top-left cell);
  `favicon.ico` (16/32/48 PNG-in-ICO) and `apple-icon.png` (180px, opaque)
  are rendered from it with `sharp`. Re-render both when the SVG changes.
- `components/ui/` — shared primitives: `Button` (+ `buttonClass` for
  non-button elements such as a file `<label>`; `size="adaptive"` is 40px
  on phones, 28px from `regular:`), `TabButton`, `SegmentedControl`
  (`touch` and `fill` sizes for phone controls, `disabled`), `SectionLabel`,
  `RangeField` (taller rows below `regular:`), `useMediaQuery`, and `cx`.
- `components/artifact/` — the reusable 3D `Artifact` viewer.
- `features/<name>/` — one directory per feature. Currently
  `features/archive/`, see [archive.md](./archive.md).
- `relics/` — the catalog data: one `.relic` per entry, read at build time
  by `loadCatalog()` (see [relic.md](./relic.md)).
- `app/relics/[id]/[face]/route.ts` — serves relic textures.
- `public/` — static assets served from `/` (empty for now).

Features import from `components/`, never the other way around.
- `next.config.ts` — `cacheComponents: true`, `partialPrefetching: true`,
  Tailwind Turbopack loader.

## Design tokens

`app/globals.css` defines the palette (`paper`, `surface`, `raised`, `line`,
`ink`, `ink-hover`, `muted`, `faint`), a type scale (`text-tag` 10.5px …
`text-display` 28px), tracking (`tracking-ui` −0.02em is the body default,
`tracking-label`, `tracking-spec`, `tracking-display`), shadows (`float`,
`modal`) and `ease-drawer`, all as Tailwind `@theme` tokens. The `mono`
utility sets Geist Mono, zero tracking and tabular figures — use it for every
code/number label. Breakpoints: `regular` (720px, phone vs everything
else) and `split` (900px, texture editor columns). Phone additions:
`text-touch` (16px, used for inputs so iOS does not zoom on focus),
`tracking-title`, `shadow-page`, and the `pt-safe` /
`pb-safe` / `glass` utilities (safe-area padding and the blurred bar
background). UI chrome uses tokens only; the greys inside the 3D
artifact meshes are material colors and stay local to `components/artifact/`.
Light theme only; the design has no dark mode.

## Rendering & caching

`cacheComponents` is on, so data fetching is dynamic by default and caching
is opt-in with the `'use cache'` directive (`cacheLife`, `cacheTag`). Wrap
dynamic, uncached work in `<Suspense>` so the static shell can prerender.
Do not reach for `unstable_cache` or route segment `revalidate`/`dynamic`
exports; they are the pre-Cache-Components model.

## Next.js docs for agents

`AGENTS.md` carries the `nextjs-agent-rules` block that `next dev` writes and
re-adds. It points agents at the version-matched docs in
`node_modules/next/dist/docs/`. Keep the block committed.

## Known gaps

- Catalog data is `relics/*.relic` read from disk at build time; there is
  no database, upload endpoint or pack CLI. New relics are committed by hand
  after downloading them from the texture editor. No env vars or Server
  Actions.
- No tests yet. Deployment: see [ci-cd.md](./ci-cd.md).
